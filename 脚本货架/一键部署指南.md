# 脚本货架 · 一键部署 & 迁移指南

「签到管家」的附属脚本仓库站。两种部署路径 + 一键迁移，为日后换机做好准备。

---

## 路径 A · 全新干净机器（自包含 HTTPS，推荐分享/迁移用）

docker Caddy 自动签 Let's Encrypt 证书，无需 host nginx。

```bash
# 域名部署
sudo bash install-hub.sh --access hub.example.com --email you@example.com

# 无域名：用公网 IP（自动 <ip>.sslip.io 拿免费真证书）
sudo bash install-hub.sh --access 1.2.3.4 --email you@example.com

# 纯 HTTP 兜底（无证书，COOKIE_SECURE=false，仅内网/调试）
sudo bash install-hub.sh --access 1.2.3.4 --http

# 部署 + 数据迁移一步到位
sudo bash install-hub.sh --access hub.example.com --email you@e.com --restore hub-backup-xxx.tar.gz
```

完成后打印访问地址 + 管理员账密。**种子脚本首次启动自动导入**。

## 路径 B · 与签到管家同一台 VPS（复用 host nginx）

> ⚠️ 主项目生产用 host nginx + certbot 占着 80/443。货架**不要**用 docker Caddy 抢端口，改走 host nginx vhost。

```bash
# 1. 构建前端 dist（docker 内，免装 node）
docker run --rm -v "$PWD/frontend":/app -w /app node:20-alpine \
  sh -c "corepack enable && pnpm install && pnpm build"
cp -r frontend/dist frontend_dist

# 2. 起后端（绑 127.0.0.1:8100）
docker compose up -d
```

host nginx 增加 vhost（示例）：

```nginx
server {
    listen 80;
    server_name hub.aijiaxia.cc;

    root /opt/signin-hub/frontend_dist;
    index index.html;

    location /api/ { proxy_pass http://127.0.0.1:8100; proxy_set_header Host $host; }
    location /health { proxy_pass http://127.0.0.1:8100; }
    location /assets/ { expires 1y; add_header Cache-Control "public, immutable"; }
    location / { try_files $uri /index.html; }
}
```

然后 `sudo certbot --nginx -d hub.aijiaxia.cc` 签证书。

> 前置：DNS A 记录 `hub.aijiaxia.cc → 154.9.238.144`（Cloudflare 灰云直连）。
> 同机部署需先用 `seed_admin.py` 建管理员：
> `docker compose exec -T backend python seed_admin.py --username admin --password '<强密码>'`

## 一键迁移（换机/备份）

```bash
# 旧机导出（含 backend/data + .env）
bash migrate-hub.sh export        # → hub-backup-<时间戳>.tar.gz

# 传到新机
scp hub-backup-xxx.tar.gz root@新机:/opt/signin-hub/

# 新机还原（二选一）
bash migrate-hub.sh import hub-backup-xxx.tar.gz && docker compose restart backend
sudo bash install-hub.sh --access <域名> --email <邮箱> --restore hub-backup-xxx.tar.gz   # 装机+还原一步到位
```

## 数据说明

| 路径 | 内容 |
|---|---|
| `backend/data/hub.sqlite3` | 脚本元数据 + 用户/会话（**无加密密钥**，迁移无密钥负担） |
| `backend/data/scripts/<slug>/` | 脚本源文件（manifest.yaml + main.py + …） |

迁移只需打包这两样 —— `migrate-hub.sh export` 已封装。
