## 2. Git 协调（同工作树同分支，靠纪律避免冲突）

- 两会话都留在 `feat/script-hub`，**任何一方都不要 `git checkout` 切分支**（同工作树切分支会搅乱另一方）。
- 各自 commit **只 add 自己负责的路径**，**绝不 `git add .` / `git add -A`**：
  - A：`git add 脚本货架 进度/分支/feat-script-hub.md 进度/README.md`
  - B：`git add backend frontend 进度/变更/2026-06-02-M3管家对接货架.md`
- commit 前 `git status` 确认只 staged 自己的文件；错开 commit 时间避免 index lock。
- push 前先 `git pull --rebase origin feat/script-hub` 拉对方提交（rebase 不产生 merge commit）。
- 提交规范：Conventional Commits + `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`。

## 3. 接口契约（两边对齐的关键）

### 货架 API（A 提供 · 生产 `https://hub.aijiaxia.cc` / dev `http://localhost:5173`(前端 proxy)或 `:8000`(后端直连)）
| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/api/scripts` | `ScriptListItem[]`：`{slug,name,description,version,author,homepage,tags[],field_count,file_count,size_bytes,download_count,has_icon,updated_at}` |
| GET | `/api/scripts/{slug}` | 详情（+ `manifest_yaml, fields_summary, bundle_sha256, icon_svg, created_at`） |
| GET | `/api/scripts/{slug}/bundle.zip` | 标准 zip（**已用管家真实校验链验证可被接受**） |
| GET | `/api/scripts/{slug}/icon` | image/svg+xml（has_icon=false 时 404） |

- 货架已开 **CORS allow `https://jb.aijiaxia.cc`**（A 部署设 `CORS_ORIGINS`）→ 管家前端可跨域 GET 货架列表/图标。
- 管家市场页用环境变量 `VITE_HUB_URL`（默认 `https://hub.aijiaxia.cc`，dev 可设 `http://localhost:5173`）拼货架地址。

### 管家对接（B 实现）
- **后端** `POST /api/v1/scripts/upload-from-url?zip_url=<url>&force=<bool>&dry_run=<bool>&sync_to_nodes=<ids>`：
  下载 `zip_url` 字节 → 写 tmp → **复用现有** `validate_zip_safety`→`extract_zip_to_tmp`→`validate_script_dir`→`dry_run_script`→`commit_to_scripts`→`script_service.scan_all`。service 层零改，只在 `script_upload.py` 路由层加 1 个 endpoint。返回与 `/upload` 同构 `UploadResponse`。
  - ⚠️ 安全：`zip_url` 建议校验 scheme=http/https + 下载体积上限（≤4MiB）；下载用现有 httpx。
- **前端 `?import` 拦截**：`ScriptList.tsx` 加 `useSearchParams()` 读 `import`，有值则自动打开上传 Dialog，把 url 传给「从 URL 导入」分支（调 upload-from-url）。
- **市场页**：`ScriptMarketplace.tsx` 用 `apiClient`/fetch 拉 `${VITE_HUB_URL}/api/scripts` → 卡片网格 → 「安装」按钮调 `POST /api/v1/scripts/upload-from-url?zip_url=${VITE_HUB_URL}/api/scripts/{slug}/bundle.zip`。

### 货架 bundle 兼容性（已验证，B 可放心）
货架产出的 zip 已通过管家真实校验链（zip 安全 + 解压剥顶层 + manifest 含 apscheduler cron 校验 + slug `^[a-z][a-z0-9-]{0,40}$` + SemVer）。3 个种子脚本全过。

**🅰 已完成（货架侧，已部署）**：
