## 实施细节

### 38 环境
Ubuntu 24.04 + Docker 29.5 + Compose v5.1;**host nginx 占 80/443**(seedbox,已有 jellyfin vhost
+ default_server `ca.aijiaxia.cc ... _`);8100 空闲;内存 7.8G / 磁盘 116G 余量充足;无 host node(dist 走 docker)。

### 部署(host nginx vhost 路径,仿 154 主站)
- `git clone -b feat/script-hub https://github.com/qiuridong/-web.git /opt/sign-hub-src`(货架在子目录 `脚本货架/`)。
- `脚本货架/deploy/部署hub2备份站.sh`:docker `node:20-alpine` 构建前端 dist(`index-CgTcy8cD.js`,与主站同 hash)
  → `frontend_dist` → `docker compose up -d --build` 起后端容器(127.0.0.1:8100,healthy)。
- **坑①**:cwd 是中文目录 `脚本货架`,`docker compose` 无法从中文目录名推导项目名(报
  `project name must not be empty`)→ `.env` 必须显式 `COMPOSE_PROJECT_NAME=signin-hub2`。
- nginx vhost `脚本货架/deploy/nginx-hub2.conf`(server_name hub2.aijiaxia.cc,root 指向 **ASCII 软链**
  `/opt/signin-hub2-dist → 脚本货架/frontend_dist`,避免中文路径)+ `/api/`→8100 + SPA fallback;
  `nginx -t` 过、`reload`,不影响 jellyfin/default_server。
- certbot LE 证书(DNS 用户已加 hub2→38 直连):`certbot --nginx -d hub2.aijiaxia.cc --redirect`
  → HTTPS + 80→443 跳转,证书 2026-08-31 到期 + 自动续期。
- 后端 CORS 已硬编码 `allow_origins=["*"]`(公开读),hub2 开箱即用,无需配 CORS。

### 每日同步 154 → 38(pull 模型,逻辑全在备份机)
- `脚本货架/deploy/sync-to-hub2.sh`(部署到 38 `/opt/sync-hub2.sh`):
  1. SSH 154 → hub 容器内 `sqlite3 .backup`(WAL 安全一致快照)→ tar(db + scripts)
  2. scp 拉到 38 → 原子替换 `backend/data`(旧库留 `.prev` 可回滚)+ 清 `-wal/-shm`
  3. `docker compose restart backend` + health 校验
- 38→154 免密:38 上专用 `/root/.ssh/hub2-sync`(私钥只在 38),其 pub 加到 154 root
  authorized_keys(带 `from="38.49.208.71"` 源 IP 限制)。
- **坑②**:`docker compose exec -T` 会**吞掉经 stdin(heredoc / `base64 -d|bash`)喂入的脚本剩余行**
  当作容器 stdin → tar/echo 不执行、快照静默失败。**必须给 docker exec 加 `< /dev/null`**。
- cron(38):`0 4 * * * /opt/sync-hub2.sh >> /var/log/hub2-sync.log 2>&1`。

## 回滚预案

- **下线 hub2 nginx**:`rm -f /etc/nginx/sites-enabled/hub2.aijiaxia.cc && systemctl reload nginx`。
- **停后端**:`cd /opt/sign-hub-src/脚本货架 && docker compose down`。
- **停同步**:`crontab -e` 删 sync-hub2.sh 行;撤销 154 授权:删 154 authorized_keys 里 `hub2-sync@38` 行。
- **数据回滚**:38 上 `backend/data.prev` 是上一次同步前的库。
- 证书:`certbot delete --cert-name hub2.aijiaxia.cc`(如需)。
