## 实施细节

### P0 · Tabs 横向溢出(根源修基类)
- **文件**:`frontend/src/components/ui/tabs.tsx:15`
- **改动**:`TabsList` 基类追加 `overflow-x-auto`(`inline-flex h-10 items-center justify-center` → 中间插入 `overflow-x-auto`)
- **理由**:`TabsTrigger` 基类带 `whitespace-nowrap`(tabs.tsx:30),6 个不换行的 tab 总宽超 360px 视口,`TabsList` 是 flex 容器但无横向滚动 → 溢出被祖先 `overflow-x-hidden` 裁掉 → 后面 tab 点不到。在基类加 `overflow-x-auto` 一次根治 ScriptDetail:282 / Settings:116 / NotificationHub:123 三处同款 `w-full` TabsList,保持 nowrap 但可横滑。box-shadow(active tab `shadow-sm`)不计入滚动溢出,不会引入多余竖向滚动条。
- **回归检查**:`ScriptList.tsx:368` 小号 inline tabs(2 项、`h-9`,卡片/表格切换)加 `overflow-x-auto` 无害(内容本就不溢出,不出现滚动条);`UploadScriptDialog` 的 `grid w-full grid-cols-2` Tabs 是 grid 布局,`overflow-x-auto` 对其无影响。

### P1 · 固定多列网格加移动断点
逐个把无断点的 `grid-cols-N` 改为移动优先:
- `components/common/InstanceFormSheet.tsx:225` — `grid-cols-3` → `grid-cols-1 sm:grid-cols-3`(超时/重试次数/首次重试等待 3 数字输入框)
- `pages/settings/Settings.tsx:773` — `grid-cols-6` → `grid-cols-3 sm:grid-cols-6`(背景预设缩略图,对齐同文件 451 行主题色预设的正确写法)
- `components/common/RunDetailSheet.tsx:94` — `grid-cols-2` → `grid-cols-1 sm:grid-cols-2`(run 详情字段)
- `pages/scripts/ScriptDetail.tsx:438` — `grid-cols-2` → `grid-cols-1 sm:grid-cols-2`(概览基本信息 dl)
- `pages/scripts/ScriptDetail.tsx:725` — `grid-cols-2` → `grid-cols-1 sm:grid-cols-2`(字段额外属性 dl,`text-[11px]`)
- `pages/notifications/NotificationHub.tsx:958` — `grid-cols-2` → `grid-cols-1 sm:grid-cols-2`(规则表单 作用域/事件 2 Select)
- **理由**:窄屏固定多列每列被压到 ~90px,label 折行、输入框极窄、值被 truncate;加 `grid-cols-1` 起步、`sm:`(≥640px)恢复多列。`cn()` = twMerge,后写 utility 覆盖前面,追加断点类安全。

## 续 2 · 2026-07-02 · README tab 内容截断修复(overflow-hidden 反噬)

> 用户反馈:详情页 README tab 文字虽不再溢出,但**被裁断**——既不隐藏也无法滑动查看被切掉的内容(尤其宽表格)。

- **根因**:上一批移动适配给 ReadmePanel 的 `Card` 加了 `overflow-hidden`(想"防溢出"),但它对无法换行的宽块(GFM 表格等)是**静默裁切**——用户看不到被切掉的列,也没有滚动条可看。典型的"fail-hidden"反模式。
- **主流修复**(GitHub/文档站标准做法):`ScriptDetail.tsx:771` ReadmePanel ——
  - ① `Card` 去掉 `overflow-hidden`(不再静默裁切,超宽内容宁可可见/可滚,不隐藏)。
  - ② ReactMarkdown `components` 加 `table` 覆盖,把每个表格包进 `<div className="overflow-x-auto">`——宽表格在自己的盒子里横向滚动,既不撑破页面也不被裁。
  - 文字仍 `break-words` 换行、代码块 `prose-pre:whitespace-pre-wrap`+`prose-pre:overflow-x-auto`(正常按空格换行、长 token 可横滑)、长链接 `prose-a:break-all`。
- **构建部署**:本地 `pnpm build`(11.01s)→ 新 hash **`index-C6Iy98FG.js`**(前序 `index-DwMZPnzz.js`)→ scp `dist.staging` 校验 → 原子切换(备份 `dist.backup.20260702-113300`)→ 公网 200 + 新 hash 生效 + 旧 hash `index-DwMZPnzz` 引用归 0。
- **回滚**:`cd /opt/signin-panel/frontend && mv dist dist.bad && mv dist.backup.20260702-113300 dist`。
- **提交**:本会话经用户授权,把含本修复的 7 个 `.tsx`(其中 `ScriptDetail.tsx` 一并含 P1 网格 + README 截断修复两处)+ 进度文档提交(排除 jmcomic 调试 png,已删)。
