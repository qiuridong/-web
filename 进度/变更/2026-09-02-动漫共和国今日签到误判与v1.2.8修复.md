# 动漫共和国“历史勾选误判今日签到”与 v1.2.8 修复

> 日期：2026-09-02
> 范围：生产 instance `5`、UK Agent、`poc34` AVD、任务中心当日状态判定
> 结论：用户指出的误判属实。v1.2.5 把累计奖励区的“第 1 天勾选”当成“今天已签到”；v1.2.8 已改为视觉定位 + Android accessibility 当日语义复核。真实管家 run `107` 已在 `ready=1.0/signed=1.0` 的历史勾选页面上实际完成新一天签到，run `108` 随后验证重复运行不再点击。

## 1. 用户更正与生产证据

用户明确指出：奖励区第一天的勾选会跨日保留，只能说明历史上完成过第一天，不能证明今天已经签到。

生产 DB 与 run `100` 日志直接证实这个问题：

- run `100` 是 2026-09-01 08:20（Asia/Shanghai）的 scheduled run，脚本版本为 `1.2.5`。
- 任务页视觉分数同时为 `ready=1.0`、`signed=1.0`，其中 `ready=1.0` 表示顶部仍有圆形“签到”按钮，`signed=1.0` 只来自历史第一天奖励勾选。
- v1.2.5 将奖励勾选置于更高优先级，直接返回 `task_signed`，结果为 `already_checked_in=true`；该 run 没有 `success_dialog_seen`，也没有执行签到动作。
- 用户进入 App 后确认当天实际没有签到，因此 run `100` 是假成功，不能作为成功记录使用。

对应日志核心行：

```text
UI 状态 phase=navigate_task surface=task_signed confidence=0.998
scores={"layout":0.998...,"nav":0.999...,"ready":1.0,"signed":1.0}
```

## 2. 可靠的“今天状态”证据

本轮从真实 `poc34` 页面同时读取截图和 `uiautomator dump`，确认 Flutter 已暴露可稳定使用的 accessibility 语义：

- **今天待签到**：任务页顶部存在精确 `content-desc="签到"` 的可点击按钮，位于任务页头部区域。
- **今天已签到**：顶部“签到”按钮消失，改为数值节点 + 精确 `content-desc="金币"` 节点。
- 奖励区的“第1天”“第2天”等勾选不参与最终当日状态判断。
- 账号金币余额数值会变化，因此只核实“金币”语义及同区域数字节点，不匹配固定余额图片。

真实已签页面的语义证据为：

```text
surface=task_signed
proof=accessibility_coin_balance
selected_tab=task
```

这比“某个奖励圆内出现勾”更直接，也不依赖不同账户的金币余额。

## 3. v1.2.8 实施

### 3.1 当日状态判定

- 视觉分类中，顶部“签到”按钮的 `ready` 证据优先于历史奖励勾选；即使 `ready=1.0` 与 `signed=1.0` 同时出现，也返回 `task_ready`。
- 任务结构已确认但局部模板变化时返回 `task_page`，交给主流程语义复核，不再直接落入 `unknown`。
- 新增 `uiautomator dump` 语义解析，只接受任务页顶部区域中的：
  - `accessibility_signin_button` → 今天待签到；
  - `accessibility_coin_balance` → 今天已签到。
- 历史奖励勾选单独出现时返回 `ambiguous_task_header`，按 fail-closed 处理，不返回成功。
- 签到前必须由语义树明确证明顶部“签到”按钮存在；点击后必须看到成功弹窗或进入已签视觉页，并再次由“金币”语义证明已签到。
- 运行结果新增 `checkin_proof`，管家日志可以直接区分成功依据，不再只看 `already_checked_in`。

### 3.2 任务底栏恢复

修复部署过程中又复现了一个独立的触摸恢复边界：底栏触摸偶发进入“频道”等非目标页，视觉分类为 `unknown`，旧状态机会空等到超时。

- accessibility 同时读取底栏 `selected=true` 的 `发现/频道/任务/我的` tab。
- 视觉为 `unknown` 时不盲点；只有语义树明确选中某个非任务底栏页，才安全重试固定“任务”坐标。
- 若任务页顶部语义已经出现，即使视觉仍是 `unknown`，也可直接恢复到 `task_ready/task_signed`。
- 重试仍受原 6 次上限约束，登录页、弹窗或无法解释的 unknown 页面不会盲点。
