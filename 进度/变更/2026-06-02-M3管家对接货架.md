## 实施细节

### 后端 · `POST /api/v1/scripts/upload-from-url`
- **文件**：`backend/app/api/v1/script_upload.py`
- **改动**：
  - 新增端点 `?zip_url=&force=&dry_run=&sync_to_nodes=`:用 httpx 流式下载远端 zip → 写 tmp → `extract_zip_to_tmp` → 复用入库。
  - 抽出共享 helper `_finalize_ingest(...)`:把原 `upload_script` 的「校验目录 → dry-run → 原子落盘 → scan 入库 → 构造 UploadResponse」整段抽出,`/upload`(zip body / multipart)与 `/upload-from-url`(远端下载)两端点共用,**两份逻辑不漂移**。
  - 新增 `_download_zip_from_url(...)`:scheme 校验(仅 http/https)+ 体积上限(`MAX_REMOTE_ZIP_BYTES=4 MiB`,Content-Length 预拒 + 流式累计中止)+ 超时(30s);远端非 200 / 网络错 → `ExternalServiceError`(502)。
- **理由**：契约要求 service 层零改、只在路由层加 1 个端点。抽 `_finalize_ingest` 是为复用而非改写既有流程(回归测试 30/30 证明 `/upload` 行为不变)。4 MiB 下载上限比单 zip 解压上限(1 MiB)宽松,留压缩比/传输头余量;真实 bundle 通常 < 50 KB。下载用项目已有的 httpx(`pyproject` 已声明)。

### 前端 · hook `useUploadScriptFromUrl`
- **文件**：`frontend/src/api/hooks/useUploadScriptFromUrl.ts`(新建)
- **改动**：`useMutation` 调 `apiClient.POST('/api/v1/scripts/upload-from-url?...')`,复用 `useScriptUpload` 的 `UploadResponse`/`UploadError` 类型;成功 invalidate `['scripts']`+`['dashboard']`。错误从本项目包络 `{error:{message}}` 解包出可读消息,`detail` 保留完整 body。

### 前端 · `?import` 拦截 + 上传 Dialog「从 URL 导入」分支
- **文件**：`frontend/src/pages/scripts/ScriptList.tsx`、`.../components/UploadScriptDialog.tsx`
- **改动**：
  - `ScriptList` 加 `useSearchParams` 读 `?import=<url>`:自动打开上传 Dialog 并把 url 透传;消费后 `setSearchParams(replace)` 清掉 query(避免刷新/返回重复触发)。顺带在页头加「脚本市场」入口按钮。
  - `UploadScriptDialog` 加 `importUrl` prop + 顶部「本地文件 / 从 URL 导入」Tabs 分支:URL 模式显示 URL 输入(http(s) 校验),提交走 `useUploadScriptFromUrl`;`importUrl` 存在时自动切 URL 分支 + 预填 + **默认关 dry-run**(货架成品脚本多需真实凭证,空 config dry-run 必失败)。slug 字段仅本地文件模式显示(URL 模式 slug 取自 manifest)。

### 前端 · 脚本市场页 + 路由 + 导航
- **文件**：`frontend/src/pages/scripts/ScriptMarketplace.tsx`(新建)、`app/router.tsx`、`components/layout/AppLayout.tsx`
- **改动**：
  - `ScriptMarketplace`:用 `VITE_HUB_URL`(默认 `https://hub.aijiaxia.cc`)`fetch ${HUB}/api/scripts` → 卡片网格(图标/名称/版本/描述/标签/文件数/大小/下载数/作者)+ 搜索。「安装」调 `upload-from-url`(`zip_url=${HUB}/api/scripts/{slug}/bundle.zip`,**dry_run=false**:结构校验仍在,跳过 sandbox dry-run,与扫描入库同级);409 冲突 → 按钮变「覆盖安装」(force=true);图标 `<img>` 失败回落首字母色块。
  - `router.tsx`:注册 `/scripts/marketplace`(放在 `scripts/:slug` 之前,避免被动态段吞掉)。
  - `AppLayout.tsx`:`NAV_ITEMS` 加「脚本市场」+ 导航高亮改**最长匹配**(`/scripts/marketplace` 只点亮「脚本市场」而非也点亮「脚本」)。
- **理由**：浏览器直读货架需货架 CORS 放行管家 origin(🅰 部署设);安装是管家后端→货架的服务端下载(无 CORS 问题)。
