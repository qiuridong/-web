## 问题清单（按严重度）

### 🔴 P0 · 用户报告的 bug：详情页 Tabs 横向溢出（手机点不到后面的 tab）

- **文件**：`frontend/src/pages/scripts/ScriptDetail.tsx:282`
  ```jsx
  <TabsList className="h-10 w-full justify-start gap-0.5 rounded-md border-b border-border bg-transparent p-0">
  ```
- **根因链**：
  1. 该 `TabsList` 有 6 个 tab（`ScriptDetail.tsx:283-308`：概览/实例/配置 schema/执行历史/实时日志/README），每个带图标，「实例」还带数量 Badge。
  2. 底层 `TabsTrigger` 基类带 `whitespace-nowrap`（`frontend/src/components/ui/tabs.tsx:30`）；`DetailTab` 自定义 className（`ScriptDetail.tsx:421-425`）未覆盖它 → 每个 tab 不换行。
  3. `TabsList` 是 `w-full` flex 容器但**没有 `overflow-x-auto`**。6 个不换行 tab 总宽远超手机视口（~360px）→ 横向溢出 → 被祖先 `overflow-x-hidden` 裁掉 → **「概览」之后的 tab（尤其实时日志、README）在手机上够不到、点不了**。与用户现象吻合。
- **修复方向**：给该 `TabsList` 加横向滚动（`overflow-x-auto`，保持 nowrap 但可滑）。最小改动。
- **根源建议**：直接在 `frontend/src/components/ui/tabs.tsx:8-20` 的 `TabsList` 基类加 `overflow-x-auto`，可一次性根治所有页面同类 tab 溢出。
- **同模式（同缺 `overflow-x-auto`，风险较低，建议一并修）**：
  - `frontend/src/pages/settings/Settings.tsx:116`（4 个 tab：账户/外观/备份/关于）
  - `frontend/src/pages/notifications/NotificationHub.tsx:123`（2 个 tab：渠道/规则，当前基本不溢出）

### 🟡 P2 · 固定像素宽度（在 flex-wrap 内，风险低）

Select 触发器硬编码宽度，好在都在 `flex flex-wrap` 工具栏里会换行、不撑破页面，但窄屏单控件仍偏宽：

- `frontend/src/pages/runs/RunList.tsx:464/480/495` — `w-[200px]` / `w-[130px]` / `w-[130px]`
- `frontend/src/pages/instances/InstanceList.tsx:502/518` — `w-[200px]` / `w-[120px]`
- `frontend/src/pages/scripts/ScriptDetail.tsx:353` — `w-[280px]`（实时日志 run 选择器，360px 屏偏挤，但父级 `flex-wrap` 会换行）
- `frontend/src/pages/scripts/ScriptList.tsx:357` — `w-[120px]`
- **建议**：改 `w-full sm:w-[200px]` 之类。优先级低。

### ⚪ 页面容器 padding 一致性（非 bug，顺带）

多数页面根容器用固定 `px-6 py-8`（`ScriptDetail.tsx:177`、`Settings.tsx:112`、`NotificationHub.tsx:116`、`RunList.tsx:411`、`InstanceList.tsx:461`、`ScriptMarketplace.tsx:168`、`ScriptList.tsx:288`），而外壳 `AppLayout.tsx:667` 已是移动优先 `px-3 py-4 sm:px-6 sm:py-6 lg:px-8`。页面内层固定 `px-6` 在手机上是双重 padding 且不随断点收窄。不致溢出，但与外壳策略不统一，建议统一为 `px-4 sm:px-6`（`Dashboard.tsx:107` 已做对）。
